- Work: **Eye Dropper**, by Timothy Dilich (The Noun Project, icon 13577).
- Source and license record: https://commons.wikimedia.org/wiki/File:Eye_Dropper_-_The_Noun_Project.svg
- Original SVG: https://upload.wikimedia.org/wikipedia/commons/2/23/Eye_Dropper_-_The_Noun_Project.svg
- License: **CC0 1.0 Universal Public Domain Dedication**, https://creativecommons.org/publicdomain/zero/1.0/
- Attribution is not required. This record is retained only for provenance.

`eyedropper.svg` is the original artwork. The transparent 64×64 PNGs are rotated and recolored for the app's light and dark themes. Developer asset rendering uses `tools/render-icons.cjs` with sharp; no renderer is required at runtime.

## Application icon

`app-icon.png` is the AI-generated artwork approved for Color Ramp: a rainbow wheel on a dark rounded tile with an eyedropper overlay (variant B). It was created with the built-in image-generation tool. `app-icon.ico` contains nine sizes from 16 to 256 pixels, built with `tools/build-app-icon.cjs`. The CC0 record above applies to the separate toolbar eyedropper artwork.
